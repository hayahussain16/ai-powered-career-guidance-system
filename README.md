# AI-Powered Career Guidance System

## Overview
This project is an AI-based career guidance system that provides personalized recommendations using user skills, interests, and preferences, supported by basic machine learning concepts and rule-based logic.

## Key Features
- Recommends suitable career paths based on user inputs  
- Uses rule-based logic with basic ML concepts for decision-making  
- Structured workflow from input processing to final recommendation  
- Improved through testing and feedback  

## Approach
- Defined project objectives and user requirements  
- Collected and structured input data  
- Designed recommendation logic (rule-based + basic ML approach)  
- Tested and refined outputs for better accuracy  

## Tools Used
- Python (basic machine learning logic)
- Excel
- Google Colab

## Use Case
Helps students and freshers make informed career decisions based on their strengths and interests.
